# OVA hero image catalog

Every image the OvaEmail agent is allowed to pick as a hero photo, in one folder, next to the real description the agent is actually shown when choosing. This file is generated from `image_bank.py`'s `HERO_BANK` - the same dict the Copywriter prompts from - so it can never drift out of sync with what the agent really sees. Do not hand-edit the descriptions here; edit `image_bank.py` and rerun `python3 build_hero_catalog.py`.

There is also always a `none` option (a deliberate text-only email, no hero) that has no image file since it renders nothing.
